# 内容生产与独立分发台

内容生产负责生成、改写、编辑和导出文章。独立分发台 `/publishing` 负责稿件、素材、平台账号和分发任务；无须先生成文章即可访问。内容生产页的“打开分发台”始终可用。

## 将生成内容加入分发台

- 单篇：文章结果区点击“加入分发台”，保存当前编辑内容，并携带历史稿件中已有的标题、摘要、标签、封面和原创标记。
- 批量：勾选已有正文的文章，选择原文版或图文版，点击“勾选稿件加入分发台”。也可从单篇预览加入当前版本。
- 按发布计划生产：选择已完成或待复核的文章，系统按底层批次导入。视频文案继续通过现有导出流程交付。
- 导入仅保存独立稿件，不创建平台发布任务。来源、版本和质量提示保存在分发稿件中；重复导入同一版本返回已有稿件。

## 在分发台直接取稿

分发台支持新建或粘贴文章、从内容生产选择，以及导入 Word（`.docx`）、Markdown、TXT 文件。文件先解析预览，确认后保存；图片或排版解析问题会提示。

## 分发执行

选稿后再选择平台账号、草稿或发布方式以及执行时间，经过平台能力预检后创建任务。未验证或尚未支持的能力保持拦截。任务使用创建时的稿件版本，后续编辑不覆盖已创建任务。

## 共用内容格式

Markdown 与净化后的富文本 HTML 均保留。表格在 Markdown 中保留原语法，富文本中保留表格结构；标题与正文重复的一级标题会整理。脚本、事件处理器和不安全链接会在提交前移除。公共实现位于 `src/lib/article-publishing/content.ts`。

旧浏览器扩展发布助手及其安装、网站信任授权、账号刷新和消息桥接已移除。历史文章数据中的标题、摘要、标签、封面、原创标记仍可导入独立分发台。

## 登录与分发稳定性（2026-10-21）

- 登录窗口保存 Cookie、LocalStorage、IndexedDB 和 SessionStorage。SDK 收到平台更新的 Cookie 时写回加密存储；浏览器适配器回传最新状态。后台更新带版本校验，旧窗口不会覆盖重新授权后的凭据，也不会恢复已退出的账号。
- 打开的账号窗口独占该账号；登录核验成功后自动保存并关闭窗口，释放账号让队列继续，无须再点关闭。关闭阶段保存最终浏览器状态，不重复请求平台核验；旧版本状态仍受写回保护。
- 登录画面请求维持窗口使用状态；页面刷新、关闭或断线后，连续 90 秒无人查看的窗口自动回收，单次窗口仍保留 30 分钟上限。回收等待中的核验不阻塞其他账号调度；关闭失败也释放账号占用。页面将自动关闭视为正常完成，停止截图轮询。
- 明确登录过期时，该账号全部未提交任务等待登录。HTTP 403 / 平台验证提示单独显示为“待平台验证”，保留会话并暂停该账号；用户在账号窗口完成验证后再检查登录状态。其他账号继续执行。
- HTTP 429 按 `Retry-After` 和退避时间中较晚者等待。连接错误也按账号退避，恢复后自动重试。发布前检查连续失败最多自动尝试 4 次；审核查询另有次数上限。提交结果不明时保留“待核对”，不自动重发。
- 批次间隔和滚动 24 小时上限按账号共用。重叠的待执行任务及近 24 小时提交采用较严格设置；真实平台至少相隔 1 分钟，本地演示不设这一保底间隔。额度在实际提交前占用，中断或结果不明也计入，防止重试突破上限。0 表示未额外设置上限，并不代表平台没有限制。
- 页面显示最近核验成功时间、登录状态保存时间、验证原因和下次尝试时间。请求限速并不表示内容推荐流量受限；平台未给出登录有效期时不推算有效期。

### 独立执行进程

生产环境复用现有 PM2。`ecosystem.config.cjs` 在 `GEO_LOCAL_PUBLISHING=1` 时增加 `geo-publisher`，使用 `LOCAL_PUBLISHER_NODE` 指定的 Node.js（至少 22.13，建议使用已有 Node 24），并以 Unix socket 为网页提供服务。socket 默认位于 `LOCAL_PUBLISHER_DATA_DIR/publisher.sock`，权限为 0600，仅限本机同一系统用户访问，不开放新公网端口。数据目录和 `session.key` 应使用固定路径，不随代码目录替换。

部署顺序：暂停队列并等待执行中的任务结束；备份 SQLite 和 `session.key`；替换经过校验的代码；启动 `geo-publisher`；确认 socket 健康后用更新后的配置重启 `geo-system`；恢复原先未暂停的队列。启用 socket 后，网页连接失败不会启动第二个执行器。网页重启不会中断队列；执行器退出由 PM2 重启，SQLite 记录用于恢复。强制中断时，未提交任务恢复排队，已经进入提交阶段的任务先核对结果。

本地开发继续支持原有子进程方式；测试独立方式可设置 `LOCAL_PUBLISHER_SOCKET` 后分别启动 daemon 和 preview。生产中保持固定的服务器出口与浏览器版本，避免频繁迁移登录环境；此功能没有新增代理轮换或浏览器伪装。

### 验收与适用边界

自动化覆盖账号整体暂停、凭据更新和版本冲突、Cookie 域与有效期、跨批次节流、执行器强制重启、网络恢复、平台验证与重新登录后恢复。界面测试只在 `DEMO_CSDN` 保存草稿，不触碰真实平台发布。

长期登录有效性由各平台决定。当前回归证明的是故障处理和恢复逻辑，不能替代 CSDN 等真实平台 7–14 天的低频草稿观察，也不承诺永久在线或推荐流量。未经过真实账号验收的平台继续显示待验证；官方 OAuth/刷新凭据接入需对应平台实际开放的权限，不自动以网页登录 Cookie 冒充 OAuth。
