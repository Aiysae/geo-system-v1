# 多平台文章发布

文章生成工作台通过本机浏览器扩展把文章交给各平台编辑器。系统服务器不接收社媒账号密码、Cookie 或登录令牌。

## 内容格式

- 同时发送 Markdown 与经过净化的富文本 HTML。
- GFM 表格在 Markdown 通道保留原语法，在富文本通道转换为内联样式 HTML 表格。
- 重复的一级标题会从正文中移除，标题通过平台标题字段单独发送。
- 脚本、事件处理器和不安全链接会在发送前移除。

## 发布桥接

当前桥接兼容 [MultiPost](https://github.com/leaperone/MultiPost-Extension) 的公开扩展 API。MultiPost 使用 Apache-2.0 许可证，用户需要在本机浏览器安装扩展，并对当前网站域名授权。

默认发布方式为“检查后发布”。开启“自动发布”后，是否能直接提交仍取决于目标平台的登录状态、验证码、风控和编辑器版本。

## 已知边界

- 部分平台会自行清理表格颜色或边框，但表格行列内容仍会保留。
- 平台页面结构变化后，对应扩展适配器可能需要升级。
- 第一版的发布结果由扩展弹窗和平台页面展示；后续可增加服务端任务记录与逐平台回执。
