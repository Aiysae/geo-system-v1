# 内容生产与独立分发台

内容生产负责生成、改写、编辑和导出文章。独立分发台 `/publishing` 负责稿件、素材、平台账号和分发任务；无须先生成文章即可访问。内容生产页的“打开分发台”始终可用。

## 将生成内容加入分发台

- 单篇：文章结果区点击“加入分发台”，保存当前编辑内容，并携带历史稿件中已有的标题、摘要、标签、封面和原创标记。
- 批量：勾选已有正文的文章，选择原文版或图文版，点击“勾选稿件加入分发台”。也可从单篇预览加入当前版本。
- 按发布计划生产：选择已完成或待复核的文章，系统按底层批次导入。视频文案继续通过现有导出流程交付。
- 导入仅保存独立稿件，不创建平台发布任务。来源、版本和质量提示保存在分发稿件中；重复导入同一版本返回已有稿件。

## 在分发台直接取稿

分发台支持新建或粘贴文章、从内容生产选择，以及导入 Word（`.docx`）、Markdown、TXT 文件。文件先解析预览，确认后保存；图片或排版解析问题会提示。

## 分发执行

选稿后再选择平台账号、草稿或发布方式以及执行时间，经过平台能力预检后创建任务。未验证或尚未支持的能力保持拦截。任务使用创建时的稿件版本，后续编辑不覆盖已创建任务。

## 共用内容格式

Markdown 与净化后的富文本 HTML 均保留。表格在 Markdown 中保留原语法，富文本中保留表格结构；标题与正文重复的一级标题会整理。脚本、事件处理器和不安全链接会在提交前移除。公共实现位于 `src/lib/article-publishing/content.ts`。

旧浏览器扩展发布助手及其安装、网站信任授权、账号刷新和消息桥接已移除。历史文章数据中的标题、摘要、标签、封面、原创标记仍可导入独立分发台。
