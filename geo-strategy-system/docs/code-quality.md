# Phase 1：统一测试与 CI

## 运行

```bash
npm ci
npm test
```

入口 `scripts/run-all-tests.mjs` 自动发现 `scripts/` 顶层的 `test-*.mts`、`test-*.mjs`、`test-*.ts`、`test-*.js`，按文件名顺序执行。每个文件复用 package.json 中现有的启动命令，保留 `NODE_OPTIONS` 和 `NODE_ENV` 等条件。

单项失败继续运行，结尾输出总数、通过数、失败数、跳过数和失败／跳过清单。有失败或没有发现测试时退出码为 1，否则为 0。新增测试缺少 npm 命令或有多个命令映射时计为失败，避免静默漏测。

唯一确认的默认跳过项是 `test-desktop-download-ui.mjs`：它需要已启动的应用及 Playwright Chromium。准备好这两个条件后，通过 `SHITU_UI_TEST_URL=http://127.0.0.1:3000 npm test` 纳入运行；指定 URL 后的连接或浏览器失败会计入失败，不会自动跳过。

`smoke:*`、`stress:*` 的真实模型调用及独立 desktop 包测试不在本次顶层脚本集合内。普通测试沿用各脚本的模拟响应及隔离存储，不加载生产环境文件。
