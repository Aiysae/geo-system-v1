## 一、生图模型选型（官方原价，华北2 北京）

| 模型 | 单价 | 新开通免费额度 | 备注 |
|---|---|---|---|
| wanx2.0-t2i-turbo | 0.04 元/张 | 500 张 | 最便宜，但属于早一代模型，画质和构图明显落后，不推荐做商用封面 |
| **z-image-turbo（关闭提示词改写）** | **0.10 元/张** | **100 张** | 通义新一代轻量模型；开启改写为 0.20 元，我们自己写好提示词，关闭改写即可 |
| qwen-image-2.1-turbo | 0.10 元/张 | 10 张 | 千问图像新一代 turbo，作为备选 |
| doubao-seedream-5.0-flash | 约 0.12 元/张 | — | 火山方舟，官方价格页不同版本数字有出入，需控制台核实 |
| wan2.2-t2i-flash | 0.14 元/张 | 100 张 | |
| qwen-image-3.0 | 0.18 元/张 | 10 张 | |
| wan2.6-t2i / wan2.2-t2i-plus | 0.20 元/张 | 50 / 100 张 | 万相目前的主力版本 |
| doubao-seedream-5.0-lite | 0.22 元/张 | — | |

**结论：默认用 z-image-turbo（关闭改写，0.1 元/张），qwen-image-2.1-turbo 做备选。** 两者同价，开发时用同一批 Prompt 各出 10 张做对比，再锁定默认模型；系统里模型可切换。两者都走百炼，系统里已经接了百炼（通义）的密钥，不用另开账号。

关键做法：**封面和配图里的中文字不让模型画**，模型只出“无字画面”，标题、大字由系统按品牌字体叠加上去。这样不会出错别字，风格统一，也能用最便宜的模型。

单条视频生图成本估算：图文视频约 8 张配图 + 1 张封面 ≈ 0.9 元；数字人口播只需封面 ≈ 0.1 元。

## 二、完整成片的技术路线

### 1. 图文视频：全部可以免费自动完成

文案（现有大模型）→ 配图（0.1 元/张）→ 配音 → FFmpeg 合成（图片缓慢推拉、转场、烧录字幕、背景音乐、AI 标识）→ 出 MP4。

- 配音：开源 CosyVoice 可本地免费跑（支持 10 秒样音克隆声音）；也可用百炼 cosyvoice-v3.5-flash，0.8 元/万字符，一条 60 秒文案约 0.05 元，基本可忽略。
- 合成：FFmpeg 是开源免费的。线上服务器是 2 核 3.5G、没装 FFmpeg，第一版先在后台任务里单条排队渲染（同时只跑 1 条），观察对网站的影响，必要时再换独立渲染机。

### 2. 数字人口播（移动场景）：做法是“底片视频 + 口型替换”

1. 为每个数字人形象，真人用手机拍一段 1–2 分钟的“边走边说”底片视频（正脸清晰、光线稳定），再录 30 秒左右的干净样音。**必须有本人书面授权**，系统里要有授权确认。
2. 每条新文案：配音（用克隆的声音）→ 把底片视频的口型换成新配音的口型 → 叠字幕、片头标题、AI 标识 → 出 MP4。底片比文案短时，系统自动循环或倒放衔接。

口型替换的开源/免费方案对比：

| 方案 | 效果 | 硬件要求 | 能否在你的 Mac（M6，16G）上跑 |
|---|---|---|---|
| LatentSync 1.6（字节开源） | 目前开源里最自然 | NVIDIA 显卡，约 8G 显存起 | 不行 |
| HeyGem / Duix.Avatar（硅基开源） | 好，自带克隆流程 | NVIDIA 显卡，Windows/Ubuntu | 不行 |
| MuseTalk 1.5（腾讯开源） | 较好，偏实时 | NVIDIA 显卡 | 不行 |
| Wav2Lip | 嘴部明显发糊，不适合商用 | 可以只用 CPU | 能跑，但不推荐 |
| 百炼 VideoRetalk（付费兜底） | 好 | 云端 | 不需要本地硬件；0.08 元/秒，新开通送 30 分钟，60 秒视频约 4.8 元 |

**结论：要“免费 + 效果能商用”，需要一台带 NVIDIA 显卡的电脑（RTX 3060 12G 或以上）**，在上面部署 LatentSync 作为“口型合成服务”，网站把任务发过去、拿回视频。没有显卡时，可以按小时租云端显卡，或用 VideoRetalk 兜底。系统按“口型合成服务可切换”来做，两种都接。

### 3. 合规（必须做）

- 《人工智能生成合成内容标识办法》（2025-09-01 起施行）要求 AI 生成的视频带显式标识：成片自动加“AI 生成”角标，发布文案里加说明。
- 数字人形象只能用本人授权的肖像和声音；不提供“上传任意人照片生成数字人”的入口。

## 三、分期计划

**第二期：内容生产拆成两个入口，先把视频文案和图片批量做出来**

- 内容生产分成「文章生产」「视频生产」两个子板块，文章部分保持现状。
- 视频生产：选疑问句（沿用现有疑问句池和品牌资料）→ 选类型（数字人口播 / 图文）→ 批量生成标题、口播稿、分镜、视频简介、标签 → 按分镜批量出封面和配图 → 人工审改 → 打包下载（可直接导入剪映）。
- 生图模型接入百炼 z-image-turbo，计费记入现有积分体系。

**第三期：自动出完整成片**

- 图文视频：配音 + FFmpeg 合成，直接出 MP4。
- 数字人：形象管理（底片视频、样音、授权）→ 配音 → 口型合成（自建 LatentSync 或 VideoRetalk）→ 叠字幕和标识 → MP4。
- 成片存储：60 秒竖版 1080P 约 20–40MB，量大后要放到对象存储（OSS），不能长期堆在服务器硬盘上。

## 四、Prompt 草案 1：视频 GEO 文案生成

> 用法：系统把“本次任务配置”（品牌资料、疑问句、匹配优势、视频类型、平台、时长、已生成内容）拼在本 Prompt 后面。事实分级、禁止编造、合规边界沿用现有《品牌短视频单问题文案生成》Prompt 的第二、三节，这里不重复。

```text
# 视频 GEO 文案生成｜数字人口播 / 图文视频

## 你的角色
你是品牌短视频策划，同时懂 AI 搜索（豆包、元宝、DeepSeek、Kimi 等）如何引用视频内容。
你写的每条视频，既要让真人愿意看完，也要让 AI 搜索在回答这个问题时能直接引用。

## AI 搜索引用视频的依据（写作时必须照顾）
AI 搜索读不到画面，只读：标题、视频简介、字幕／语音转写、话题标签。所以：
1. 标题里要出现用户真实会搜的问题或长尾词，不要只写情绪化口号。
2. 口播前 3 秒，把核心疑问原样或近似地说出来。
3. 结论先行：第一个要点之前就给出明确判断，再讲依据。
4. 品牌第一次出现时说完整称呼（品牌全称 + 所在地区 + 主营品类），之后统一用同一个简称，不要混用多个叫法。
5. 关键事实写成能单独被引用的完整句子：主语 + 事实 + 适用条件。不要用“它”“这个”“我们家”指代。
6. 视频简介写成一段 150–300 字的“问答式摘要”：先复述问题，再给结论和 2–3 条依据，最后带品牌信息。这一段是 AI 最常引用的部分。
7. 只用资料里能证明的事实；没有证据就讲判断方法和验证方式，不编数字、案例、排名。

## 一条视频只回答一个疑问
只使用该疑问匹配的优势，2–3 个有递进关系的要点。和已生成内容在标题、开场、论证顺序、结尾上要明显不同。

## 按视频类型输出

### A. 数字人口播（移动场景）
数字人是一段真人边走边说的底片视频，口型会替换成新配音。写作要求：
- 口语、短句，每句 8–18 字，方便字幕两行内显示；语速按每秒 4–4.5 个字估算时长。
- 像在现场边走边讲：可以用“你看这里”“我们走到……”这类现场感表达，但不能描述底片里没有的具体物品或数据。
- 每段标出动作提示（走动／停步面向镜头／抬手示意），只作剪辑参考。
- 可以给 B-roll 建议（需要插入的产品、现场、证书画面），标明“需客户提供素材”。

### B. 图文视频
由 6–10 页竖版画面 + 旁白组成，每页 4–8 秒：
- 第 1 页是问题页：大字直接是疑问句（可缩短到 16 字内）。
- 中间页每页只讲一个点，大字 ≤12 字，旁白 1–3 句。
- 最后一页是结论或行动建议页，带品牌名。
- 每页给一句“配图描述”：写清画面主体、场景、氛围，不要写画面里的文字，不要出现真实可辨认的人脸、商标或品牌 logo。

## 输出格式
只输出一个 JSON 对象，不要任何解释文字：
{
  "type": "avatar" | "slides",
  "perspective": "本条采用的专业视角",
  "title": "发布标题（≤30 字，含核心问题或长尾词）",
  "coverTitle": "封面大字（≤14 字，可分两行，用 \n 分隔）",
  "coverImageBrief": "封面配图描述（无文字画面）",
  "description": "视频简介，150–300 字问答式摘要",
  "tags": ["#话题", "..."],
  "estimatedSeconds": 60,
  "segments": [
    {
      "voiceover": "这一段的口播／旁白",
      "subtitleKeywords": ["需要加粗变色的重点词"],
      "screenText": "仅图文：这一页的大字",
      "imageBrief": "仅图文：这一页的配图描述",
      "action": "仅数字人：动作提示",
      "broll": "仅数字人：可选的插入画面建议",
      "seconds": 6
    }
  ]
}

## 输出前自检
- 标题和前 3 秒是否说出了核心疑问？
- 是否结论先行？品牌称呼是否统一？
- 简介能否脱离视频单独回答这个问题？
- 有没有资料里没有的数字、案例、认证、承诺？
- 总时长是否接近目标时长（±10 秒）？标签数量是否符合配置？
- 图文的配图描述里是否没有文字、logo、真实人脸？
任一项不合格先在内部修改，再输出。
```

## 五、Prompt 草案 2：封面与配图生成

分两步：先让大模型把“配图描述”改写成生图提示词（所以生图模型可以关闭自带改写，省一半钱），再调用生图模型。

### 第 1 步：提示词改写（给大模型）

```text
你是短视频美术指导。把下面的“配图描述”改写成一条用于 AI 生图的中文提示词。

已知信息：
- 行业：{行业}
- 视频主题：{疑问句}
- 画面用途：{封面 | 图文第 N 页}
- 视觉风格：{写实摄影 | 简约插画 | 3D 质感 | 商务信息图底板}（同一条视频所有页风格一致）
- 品牌主色：{主色，可空}

改写规则：
1. 按“主体 → 场景 → 光线 → 构图 → 风格 → 质感”的顺序写成一段话，60–120 字。
2. 画面为竖版 9:16。封面在上方留出约 35% 的干净区域放标题；图文页在中间偏上留出放大字的位置。
3. 画面里不能出现任何文字、数字、字母、水印、商标、logo、二维码。
4. 不出现真实可辨认的人物面孔；需要人物时，用背影、手部特写、远景剪影或插画人物。
5. 不画夸张效果（例如发光的产品、爆炸特效），不画医疗、食品功效之类的暗示画面。
6. 画面要和视频主题直接相关，能让人一眼看出行业和场景。

只输出改写后的提示词，不要解释。
```

### 第 2 步：调用生图模型

- 模型：z-image-turbo，关闭提示词改写；尺寸 1080×1920 附近的竖版规格（以模型支持的分辨率为准）。
- 统一追加的反向要求：`文字，字母，数字，水印，logo，商标，二维码，畸形手指，多余肢体，模糊，低清晰度，过度锐化，塑料感皮肤`
- 风格预设（同一条视频固定一个）：

| 风格 | 追加描述 |
|---|---|
| 写实摄影 | 真实摄影质感，自然光，浅景深，干净背景，商业摄影色调 |
| 简约插画 | 扁平矢量插画，柔和配色，大面积留白，线条简洁 |
| 3D 质感 | C4D 渲染风格，柔和体积光，哑光材质，干净的浅色背景 |
| 商务信息图底板 | 浅色渐变背景，抽象几何元素，适合叠加大字与图表 |

- 生成后由系统叠加：封面标题、每页大字、品牌名、“AI 生成”角标。
